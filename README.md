# TURTLESS Engineering Notebook

> **Design · Build · Test · Iterate**

TURTLESS의 로봇 설계와 제작, 테스트 및 개선 과정을 기록하는 Engineering Notebook입니다.

이 저장소에는 단순한 최종 결과뿐만 아니라 **문제를 발견하고, 해결 방법을 설계하고, 실제로 제작하고, 테스트한 뒤 다시 개선하는 전체 과정**을 기록합니다.

---

## About TURTLESS

**TURTLESS**는 로봇공학을 기반으로 다양한 설계와 제작 활동을 진행하는 학생 로봇팀입니다.

이 Engineering Notebook은 팀의 기술적 의사결정과 개발 과정을 투명하게 기록하고, 이후의 설계와 새로운 팀원들의 학습에 활용하기 위해 운영됩니다.

---

## Engineering Process

TURTLESS는 다음과 같은 과정을 중심으로 로봇을 개발합니다.

```text
Problem
   ↓
Research
   ↓
Design
   ↓
Prototype
   ↓
Test
   ↓
Analyze
   ↓
Iterate
   ↓
Final
```

실패한 설계와 테스트 결과도 중요한 개발 과정으로 간주합니다.

## Documentation Principles

### 1. 과정 중심

최종 결과만 기록하지 않습니다.

**왜 그렇게 설계했는지**, **무엇이 실패했는지**, **어떻게 개선했는지**를 기록합니다.

### 2. 데이터 기반

가능한 경우 실제 측정값과 테스트 결과를 사용합니다.

### 3. 실패도 기록

실패한 설계와 예상하지 못한 결과도 다음 설계의 중요한 근거가 됩니다.

### 4. 지속적인 업데이트

Engineering Notebook은 완성된 하나의 문서가 아니라 프로젝트가 진행되는 동안 계속 업데이트되는 기록입니다.

## Engineering Note Format

각 기록은 가능한 경우 다음의 흐름을 따릅니다.

```text
Objective
   ↓
Background
   ↓
Problem
   ↓
Hypothesis
   ↓
Design / Approach
   ↓
Prototype
   ↓
Test
   ↓
Problems & Observations
   ↓
Iteration
   ↓
Final Result
   ↓
Conclusion
   ↓
Next Steps
```

모든 항목을 모든 기록에서 반드시 작성할 필요는 없습니다.

작은 작업은 간단하게 기록하고, 중요한 설계와 테스트는 상세하게 기록합니다.
